# 🏁 維基百科競速 · 線上對戰

和朋友一對一（或最多 8 人派對）比賽：從起點條目出發，**只能點擊條目內的連結**，誰先抵達終點條目誰就獲勝。

## 玩法

1. 輸入暱稱，按「建立房間」，取得 5 碼房間代碼。
2. 按「複製邀請連結」傳給朋友（或讓朋友輸入代碼加入）。
3. 房主設定起點／終點條目（可輸入、可按 🎲 隨機，留空開始時也會自動隨機）、語言版本、時間限制。
4. 朋友按「準備」，房主按「開始比賽」，倒數 3 秒後同時開始。
5. 比賽中可以看到對手的步數與（可選）目前所在條目；先抵達終點的人獲勝，雙方都抵達則比用時。

## 派對模式

- 首頁選「2–8 人 派對模式」再建立房間，最多 8 人一起比同一個題目。
- 所有玩家按「準備」後，房主就能開始。
- 依抵達順序與用時排名（比步數則依步數）。房主可以設定「最後衝刺」：第一個人抵達後其他人只剩 30 秒到 3 分鐘，或不限時間比到最後；投降或時間到就沒有名次。
- 先抵達的人可以看即時排行榜等其他人，結束後每個人的路線都能展開查看。

## 搶分賽

- 房間「玩法」選「🏃 搶分賽」，房主設定總時間（3／5／8／10 分鐘）和難度。
- 時間內不停找：抵達終點就 +1 分，馬上換下一題。所有人的題目順序都一樣（房主出題後依序傳給大家），每人每局可以跳過 2 題（按兩下確認，跳過不加分）。
- 難度：**簡單**、**普通**是從熱門條目出發，沿著連結隨機走 2／3 步走到的地方當終點（保證走得到）；**困難**是完全隨機的兩個條目。房主那支手機在比賽中背景補題，只比最快的人多準備幾題。
- 時間到照分數排名（一樣多分時比較早拿到最後一分的在前），1 對 1 也用排名表；投降會保留分數、不影響其他人；重新整理會接回同一題、分數和跳過次數。

## 新手第一局

第一次來的人看完教學，最後一頁按「🐣 玩第一局！」直接玩一題保證簡單的題目（題庫裡 9 題都在真的維基百科上確認過兩步就到，例如 漢堡 → 美國 → 自由女神像）；略過教學的話，首頁有「🐣 新手第一局」按鈕。比賽中下方會有小提示：每一頁先給方向，10 秒沒動就說出要找哪個連結（可以按「幫我找」），20 秒直接捲過去閃給你看；走錯路會提醒按「上一頁」，這一頁就有終點時提醒找金色連結。玩完之後按鈕就不再出現；從朋友邀請連結來的人不會被帶去玩新手局。

## 其他功能

- **🔍 找這頁的連結**：房主可以在規則裡打開「允許找連結」（預設關閉；單人訓練也可以自己打開）。比賽中下方多一個「找連結」，打字就列出這一頁符合的連結，點一下捲過去並閃一下（要不要點還是自己決定）。
- **投票提示（兩段）**：比了 3 分鐘還沒人到，提示列會問大家要不要看提示，還在比的人都同意才打開（終點條目的簡介，名稱遮起來）。比到 5 分鐘再多一個**第二個提示**：一樣要大家同意，打開後列出 3 個「有連結直接通到終點」的條目（走到其中一個，下一步就能到）；由房主挑好傳給大家，每個人看到的都一樣，不會列出起點和自己走過的條目。單人訓練不用投票直接看。

- **正確解答**：比完後可以看最短路線。用雙向廣度搜尋一定找得到（沒有步數上限，處理重新導向），找到後每一步都實際打開條目確認遊戲畫面上點得到；只有起點沒有任何連結、或沒有條目連到終點時才會說明真的到不了。路線上每一站都能直接打開維基百科，「▶ 看怎麼點」會一頁一頁示範要點哪個連結。比賽一開始就先在背景找：多人房間由房主那支手機找（一間房只找一次），單人訓練和每日挑戰自己找；比賽中放慢速度（一次只問一個、自己換頁時先讓路），不會讓比賽變卡。找到的答案只傳給比完的人（還在比的人收不到），所以大部分時候一比完就直接看得到。維基百科說太忙（429）或網路斷掉時會等一下接著找。
- **快速表情**：房間、比賽中、結算畫面都能丟表情或快捷語，會飄過所有人的畫面。
- **房內聊天**：房間與結算畫面共用聊天室，重新連線的人也看得到最近的訊息。
- **斷線重連**：玩家斷線後會自動重連；比賽中保留 60 秒、房間裡保留 15 秒。重新整理網頁也會自動回到原本的房間與進度；不小心關掉 App 再用連結或代碼回來，也會回到原本的位子（不會被當成新的人）。
- **轉移房主**：房主可以把房間交給其他玩家；房主按「離開」時房間會自動交給下一位，不會解散。
- **自動換房主**：房主斷線（關掉 App、網路斷掉）約 10 秒還沒回來，就由名單上排最前面、還在線上的玩家自動接手同一個房間，其他人自動連過去；所有人都會跳出「誰離線了、誰成為新房主」的通知。比賽中途也一樣，比賽繼續，舊房主算離開這一局。舊房主之後回來會用玩家身分回到房間。
- **房間內換玩法**：房主可以在房間裡直接切換比賽方式（比速度／比步數，可以再加道具）和人數（1 對 1／派對），不用重開房間；改了之後大家會收到通知，「準備」會被取消重新確認（房間超過 2 人時不能改成 1 對 1）。
- **房主回來接手**：房主沒按離開就不見了（不小心關掉 App、重新整理、手機把網頁收掉），在其他玩家接手之前（約 10 秒內）重新整理、點邀請連結或輸入代碼，就會用同一個代碼回到房間繼續當房主，其他人自動連回來。比賽中途不見的話會接回同一局（步數、所在條目都在，時間照算）。
- **道具**：比速度和比步數都可以打開「🎁 道具」，離終點越遠的人拿到越強的道具。
  - **比速度＋道具**：每 40 秒發一個（迷霧、天旋地轉、冰凍、香蕉皮、蝸牛、閃電、護盾、水晶球）。
  - **比步數＋道具**：每走 3 步發一個，換成跟步數有關的道具：🎒 重擔（對手下一步算 2 步）、👟 免費一步（自己下一步不算）、香蕉皮、水晶球、迷霧、天旋地轉、護盾；拖時間的冰凍、閃電、蝸牛不會出現。香蕉皮和重擔會留到對手下一次點為止（最多 2 分鐘）。
- **自選背景音樂**：大廳和比賽音樂各自選內建曲目（輕快鋼琴、8-bit 冒險、Lo-fi 放鬆、緊張節奏），或用手機裡自己的音樂檔。
- **分享戰績圖**：結算後產生一張 1080×1350 的戰績圖，可直接分享或存到相簿。

## 技術說明

- **純靜態網站**，不需要後端：`index.html`、`style.css`、`app.js`、`wiki.js`、`net.js`、`fx.js`（背景音樂、音效、觸覺回饋與特效）、`topics.js`（超過一萬個隨機條目）、`zh.js`（簡轉繁）、`share.js`（戰績圖）。
- 線上對戰使用 [PeerJS](https://peerjs.com/)（WebRTC 點對點連線），透過 PeerJS 免費的公開配對伺服器建立連線。房主當中繼站，每位玩家只連到房主。
- 條目內容即時從維基百科 API 讀取，中文版使用 `zh-tw` 台灣正體轉換；也支援英文維基。

- 隨機條目從內建的 10,000+ 題庫抽選（已排除艱澀條目），抽到時會向維基百科確認條目存在、不是消歧義頁，而且近 30 天瀏覽量夠高；英文模式透過跨語言連結轉換。
- 背景音樂與音效是由 `audio/render.py` 離線合成的 mp3，用瀏覽器原生的 `<audio>` 播放（不在手機上即時合成，避免 iPhone 雜音）。

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

（要用 http server 開，不能直接雙擊 html 檔，因為使用了 ES modules。）

## 部署到 GitHub Pages

1. 把程式合併到 `main` 分支。
2. 到 GitHub repo 的 **Settings → Pages**，Source 選 **GitHub Actions**。
3. 之後每次推送到 `main` 都會自動部署，網址為 `https://<你的帳號>.github.io/<repo 名稱>/`。

也可以部署到 Firebase Hosting、Netlify、Vercel 等任何靜態網站服務。

## 每日挑戰

首頁的「📅 每日挑戰」：全台灣每天同一題（台灣時間午夜換題），題目用日期從題庫抽出，每個人算出來都一樣。
每支手機**第一次**挑戰的成績會用暱稱登上今日排行榜（步數少的贏，同步數比時間；用過提示會標 💡），之後再玩只算練習。按下開始會先跳出提醒：起點出現後就算用掉今天的機會；中途關掉、跳出、重新整理或斷線，**3 分鐘內回來可以接著玩**（步數、路線、上一頁都接得回去，計時照算、離開的時間也算），超過 3 分鐘就算用掉了。管理員可以在後台重置今天的挑戰，讓大家再挑戰一次。
完成（或用掉今天的正式機會）之後，排行榜上可以點開每個人走的路線；還沒玩的人看不到，避免直接看到答案。
完成後可以分享成績，朋友點分享連結（`?daily`）會直接打開今天的題目。排行榜存在 Firebase 的 `stats/daily/<日期>/<登入身分>`（每個身分每天一筆、不能覆蓋）；沒設定 Firebase 時一樣能玩，只是沒有排行榜。

## 線上人數（選用）

首頁可以顯示「🟢 N 人在線上」。這需要一個免費的 Firebase 專案（遊戲本身不需要後端，只有這個計數需要）。不設定的話，首頁就不會出現這塊，其他功能一切正常。

設定步驟：
1. 用 Google 帳號登入 <https://console.firebase.google.com/>，點「建立專案」，名稱隨意，不用開 Google Analytics。
2. 左側選 **Build → Realtime Database → 建立資料庫**，位置選「新加坡（asia-southeast1）」之類離台灣近的，規則先選 **測試模式（test mode）**。
3. **安全規則不要用「任何人都能寫」**。資料庫的保護靠 Firebase 的安全規則加上登入身分（只靠後台密碼擋不住直接改資料庫的人）。規則請等網站架好後，照下面「資料庫保護」的步驟，由後台幫你產生。
4. 回到專案首頁，點 **</> 網頁**，註冊一個 App，Firebase 會給你一段 `const firebaseConfig = { ... }`。
5. 打開本專案的 `firebase-config.js`，把那段貼進去，改成：
   ```js
   window.WIKIRACE_FIREBASE = {
     apiKey: '...', authDomain: '...', databaseURL: 'https://...firebaseio.com',
     projectId: '...', appId: '...',
   };
   ```
   **一定要有 `databaseURL`**（在 Realtime Database 頁面上方看得到）。
6. 推送到 `main` 重新部署即可。

這個計數本身只記「現在有幾個人打開網站」的總數；另外後台的「在線玩家」會看到每個人的暱稱和在做什麼（只有管理員讀得到）；只有管理員按「觀戰」時才會看到那個人的畫面，而且對方畫面上會顯示。免費額度對朋友間的使用綽綽有餘。

## 製作者後台（選用）

設定好上面的 Firebase 後，`admin.html` 是一個給製作者看的營運儀表板，打開 `https://<你的網址>/admin.html` 並輸入密碼即可（密碼寫在 `admin.html` 最上面的 `ADMIN_PASS`，想改就改那一行）。後台可以看到：

- **即時概況**：現在有幾間房間、幾個人在玩、幾個人在線上、史上同時在線尖峰。
- **所有對局**：歷史統計裡有每一局的完整戰績（多人、單人訓練、每日挑戰都有）：時間、模式、題目、每個人的名次／結果／步數／時間／路線，可以用暱稱或題目搜尋。
- **趨勢**：最近 7 天／30 天每天的對局數或玩家人次（長條圖，和前一段時間比較），以及「星期幾 × 幾點」最多人玩的熱力圖（台灣時間），也可以看表格。
- **題目分析**：每一題（起點→終點）玩了幾局、完成率、平均／最少步數、投降和開提示的次數，可以照最常玩、最難、最近排序；點開看最少步數的走法，也可以直接把起點或終點拿出題庫、或設成明天的每日題目。
- **玩家檔案**：照登入帳號合併（換暱稱也算同一人），看局數、抵達率、多人第一、平均步數和時間、可疑次數、最近的對局、用過的暱稱；可以寫只有自己看得到的備註，或直接踢出。
- **每日題目**：看今天和明天的每日挑戰題目，可以自己指定或重抽一題。
- **重置今天的每日挑戰**：大家一起跳掉、或題目出問題時，按「🔄 重置今天的挑戰」（可以同一題、或順便換一題）：所有人都能再正式挑戰一次，排行榜從零開始（之前的成績留著但不再顯示）。今天已經有人玩過還要換題目時，也會自動一起重置，新舊題目的成績不會混在一起。
- **題庫管理**：太難、太冷門或不適合的條目可以拿掉，隨機出題就不會抽到（玩家自己輸入的題目不受影響）。
- **強制踢出**：在線玩家旁邊的「🚫 踢出」可以選 10 分鐘、1 天或永久。被踢的人馬上斷線、看到「你已被管理員請出伺服器」，期限內打不開遊戲，資料庫規則也擋住他寫入任何東西；「踢出名單」可以隨時解除。
- **觀戰**：在線玩家列表裡比賽中的人可以直接觀戰（玩家會看到「管理員正在觀戰」）。觀戰時下面有一個輸入框，可以**傳一句話給那位玩家**（他的畫面會跳出來，按「知道了」關掉）。
- **多人觀戰**：在線玩家上面按「🔲 多人觀戰」，選 2～4 位比賽中的玩家，畫面排成格子同時看；每格可以「放大」。
- **重播任何一局**：所有對局點開後，每個人的路線旁邊有「🎬 重播」，用跟最佳解答一樣的影片一步一步播放（可以暫停、上一步、下一步、調速度），按「上一頁」的那一步也會顯示出來。玩家在結算畫面也可以重播自己和比完的人的路線。
- **在線玩家**：每個打開遊戲的人一列：暱稱、在首頁／房間（代碼、房主或玩家、模式）／比賽中／單人訓練／每日挑戰，以及題目和目前步數。這份列表只有管理員讀得到。
- **歷史統計**：今日／本週／全部的對局數、玩家人次、完成率、再玩率、平均一局時間、平均步數、各模式分布、最常「沒人抵達」的題目。
- **正在遊玩的房間**：每間房的代碼、房主、模式、題目與每位玩家的步數進度（可依最新／人多／開最久排序、只看比賽中）。必要時可以**關閉房間**或**踢出某位玩家**。
- **全站公告**：打一句話推到所有正在玩的人畫面上（玩家可以自己關掉）。可以排程（指定開始時間）、設定顯示多久，時間到自動收起來。
- **版本分布**：在線玩家上面顯示大家開著第幾版，看得出誰還在用舊版（舊版的人回到首頁會自動更新）。
- **錯誤紀錄**：玩家那邊出錯（讀不到條目、找不到解答、程式錯誤…）會自動記下來，同樣的錯誤合在一起，顯示次數、人數、版本、瀏覽器。
- **可疑對局**：太快抵達的人（幾秒就到、平均每步不到 1.2 秒）在所有對局裡標成「⚠️ 可疑」，可以只看可疑的；對局也記了語言和有沒有開提示。
- **匯出**：所有對局可以匯出成 CSV（Excel 打得開），每位玩家一列，含路線。
- **暱稱過濾**：內建常見髒話，不雅暱稱不能用（房主收到別人的也會換成「玩家」），聊天裡的髒話變成＊；後台可以加要擋的字。
- **操作紀錄**：發公告、踢人、關房、改設定、匯出…管理員做的每件事都記下來。
- **手機通知**：有人開房間、開始第一場比賽、開始單人訓練時，推播到你的手機（見下方）。另外每晚 10 點左右會傳一則**今日摘要**（幾局、幾人次、每日挑戰幾人完成、現在在線、有沒有錯誤），可以關掉，也可以按「現在傳一次」。

後台看得到大家在做什麼。比賽中（含單人訓練、每日挑戰）的玩家旁邊有「👀 觀戰」，按下去可以看他的即時畫面（正在看的條目、捲到哪、點了什麼）；**被觀戰的玩家畫面上方會一直顯示「👀 管理員正在觀戰」**，關掉觀戰就消失，其他時候不會傳送任何人的畫面。遊戲首頁也有一行說明，讓玩家知道會收集哪些匿名的房間資訊。

### 手機通知

用免費的 [ntfy](https://ntfy.sh/) App 收推播，不用帳號、不用另外架伺服器：

1. 後台按「開啟通知」，會產生一個隨機的頻道名稱（例如 `wikirace-xxxxxxxxxxxx`）。
2. iPhone 在 App Store 下載 **ntfy**，允許通知，按 **＋** 把頻道名稱貼進 Topic 後按 Subscribe。
3. 後台按「傳一則測試通知」確認手機收得到。

可以分別開關三種事件；「我用這支手機玩的時候，不要通知我自己」會記在那支手機的瀏覽器裡。點通知會打開後台。
同一支手機同一種通知一分鐘最多一則，每間房只通知第一場比賽。

ntfy 的頻道只要知道名稱就能訂閱，所以通知內容只有模式和人數（單人訓練會附題目），**不含暱稱和房間代碼**；詳細資料請到後台看。如果覺得頻道名稱外流了，按「換一個頻道」再重新訂閱即可。

每晚的今日摘要是 GitHub Actions 的排程（`.github/workflows/nightly.yml`，執行 `scripts/nightly.mjs`），只讀 Firebase 上公開的數字（今天的局數、人次、錯誤數是 `stats/dayCount`，每日挑戰排行榜、線上人數、尖峰），不需要設定任何密碼。GitHub 的排程有時會晚幾分鐘到半小時；想馬上試可以到 GitHub → Actions → Nightly summary → Run workflow。

### 資料庫保護（安全規則）

玩家會在背景**匿名登入**（看不到任何畫面），管理員用 **Google 帳號**登入後台。安全規則（`rules.js`）的原則：

- 玩家只能寫自己的資料：自己的線上狀態、自己房間的概況、自己的每日成績（每天一筆、不能覆蓋），而且欄位要合理。
- 房間列表（有暱稱）和歷史統計只有管理員看得到。
- 公告、踢人、關房、手機通知設定、暱稱過濾只有管理員能改；後台指令只有該房的房主讀得到。
- 錯誤紀錄每人只能新增自己的、不能改；操作紀錄、玩家備註只有管理員讀寫；題庫管理和指定每日題目只有管理員能改。
- 其他路徑一律禁止讀寫。

設定步驟（後台「🔐 資料庫保護」也有）：
1. Firebase 主控台 → **Authentication** → 開始使用 →「登入方式」啟用 **匿名** 和 **Google**。
2. Authentication → **設定** → **授權網域** → 新增你的網站網域（例如 `kylechen0419.github.io`）。
3. 打開後台，按「用 Google 登入」，會出現只認你帳號的規則。
4. 按「複製規則」→ Realtime Database → **規則** → 整段換掉 → **發布**。

順序很重要：一定要先做第 1 步再發布規則，不然玩家還沒有登入身分，線上人數和排行榜會寫不進去。規則可以用 `firebase` 的本機模擬器測試（每條規則都有對應的允許／拒絕測試）。
