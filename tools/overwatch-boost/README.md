# 鬥陣特攻 2 + Discord 賽前優化包

給 **16GB 記憶體** 電腦用：解決「角色變成光球」、卡頓，並讓 Discord 通話不搶遊戲效能。

## ⚡ 最快用法：一鍵版（給不在身邊的朋友）

1. 下載：https://github.com/kylechen0419/aov/raw/claude/friendly-dirac-v3u30e/tools/overwatch-boost/OW_OneClick.zip
2. 打開 zip，**雙擊 `OW_OneClick.bat`** → 按「是」（藍色警告就按「其他資訊」→「仍要執行」）
3. 全自動，不用回答任何問題。看到「優化完成」視窗按確定後，再開 Discord 和鬥陣特攻（黑色視窗不要關）。

一鍵版會自動：健檢、切高效能電源（保留 ASUS Turbo 等品牌效能模式）、開遊戲模式、關掉 OneDrive / Teams / Spotify / Steam 等背景程式（**不會關瀏覽器**）、清暫存檔、**重建著色器快取**（修光球）、清 DNS、遊戲啟動後提高優先順序。執行記錄存在桌面 `OWBoost_log.txt`。


## 一、先搞懂：角色為什麼會變光球？

鬥陣特攻的角色「光球 / 發光圓球」其實是**角色模型與貼圖還沒讀進來時的替代畫面**。最常見的原因，依機率排序：

| 原因 | 怎麼判斷 | 怎麼解決 |
|---|---|---|
| 1. **材質品質設太高**，顯示卡記憶體 (VRAM) 不夠 | 顯示卡 VRAM ≤ 6GB、或用內顯 | 遊戲內「材質品質」改「中」或「低」 |
| 2. **遊戲裝在傳統硬碟 (HDD)** | 腳本健檢會告訴你 | 用 Battle.net 把遊戲移到 SSD |
| 3. 背景程式吃掉太多記憶體（瀏覽器、Wallpaper Engine…） | 打開工作管理員看記憶體 > 85% | 腳本第 4 步幫你關 |
| 4. 虛擬記憶體（分頁檔）被關掉 | 腳本健檢會告訴你 | 見下方「Windows 設定」 |
| 5. 著色器快取或遊戲檔案損壞 | 調低畫質還是一樣 | 腳本第 6 步 + Battle.net「掃描與修復」 |
| 6. 顯示卡驅動太舊 | 腳本健檢會告訴你 | 見下方驅動下載連結 |

> 16GB 記憶體玩鬥陣特攻是**夠的**（官方建議 8GB），所以問題通常出在 1、2、3。

## 二、一鍵優化腳本（每次打遊戲前執行）

1. 下載整個 `overwatch-boost` 資料夾（所有檔案放一起）。
   - 第一次建議先雙擊 **`0_Test_Only.bat`**：只做健檢、**不改任何設定**，結果存到桌面 `OWBoost_log.txt`。
2. **雙擊 `1_Start_Boost.bat`** → 跳出「是否允許變更」按「是」。
   - 若出現「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
3. 照畫面回答 Y / N，腳本會依序做：

| 步驟 | 做了什麼 | 可還原？ |
|---|---|---|
| 1 健檢 | 檢查記憶體、顯示卡 VRAM、驅動日期、遊戲是否在 HDD、虛擬記憶體 | 只讀取，不修改 |
| 2 電源計畫 | 切到「高效能」，CPU/顯卡不降頻 | `2_Restore.bat` |
| 3 遊戲模式 | 開啟 Windows 遊戲模式、關閉 Xbox 背景錄影 | 可在 Windows 設定改回 |
| 4 關背景程式 | 列出最吃記憶體的程式，**問你同意後**才關（OneDrive、Teams、Spotify、Epic、Wallpaper Engine…；瀏覽器另外問）| 重開程式即可 |
| 5 清暫存檔 | 清除 Windows 暫存資料夾 | — |
| 6 著色器快取 | **選擇性**清除 NVIDIA/AMD/Intel/DirectX 著色器快取（曾出現光球時建議做一次）| 會自動重建 |
| 7 網路 | 清除 DNS 快取 | — |
| 最後 | 偵測到遊戲啟動後，把鬥陣特攻設為「高」優先、Discord 設為「高於標準」| 關遊戲即失效 |

4. 腳本最後會停在「等待遊戲啟動」→ 這時打開 Discord、啟動鬥陣特攻即可。
5. 打完想恢復省電模式：雙擊 `2_Restore.bat`。

> 安全說明：腳本是純文字，可以用記事本打開檢查。不會修改 BIOS、不超頻、不刪除個人檔案、不安裝任何東西、不連網下載。

## 三、遊戲內設定（光球問題最關鍵！）

`選項 > 影像`

| 設定 | 建議值 | 說明 |
|---|---|---|
| 顯示模式 | 全螢幕 | 比無邊框視窗順 |
| 算圖比例 | 100% | 千萬不要超過 100% |
| 幀數上限 | 自訂 → 螢幕更新率（60/144/165…）| 留效能給 Discord，避免顯卡滿載 |
| NVIDIA Reflex | 開啟 + 加速 | NVIDIA 卡才有 |
| 減少緩衝 | 開 | |
| **材質品質** | **中**（VRAM ≤ 4GB 或內顯 → **低**）| ⭐ 光球主因 |
| 材質過濾品質 | 低 – 4x | |
| 局部霧氣細節 | 低 | |
| **動態反射** | **關** | 很吃 VRAM |
| 陰影細節 | 低 | |
| 模型細節 | 低 / 中 | |
| 特效細節 | 低 | 也比較好看清楚戰況 |
| 光影品質 | 低 / 中 | |
| 抗鋸齒 | 低 – FXAA | |
| 折射品質 | 低 | |
| 螢幕截圖品質 | 1x | |
| 局部反射 | 關 | |
| 環境光遮蔽 | 關 | |

改完材質品質後，**重新啟動遊戲**一次，讓設定完全生效。

## 四、Discord 設定（通話不卡、不搶效能）

- `使用者設定 > 進階 > 硬體加速`：**關閉**（讓顯示卡全力給遊戲；改完 Discord 會重開）
- `使用者設定 > 遊戲疊加`：**關閉**「啟用遊戲內疊加」
- `使用者設定 > 語音與視訊`：
  - 「降噪」選 **標準** 或 Krisp 皆可；若 CPU 很弱改「無」
  - 「服務品質高封包優先順序」：**開啟**
  - 「自動調整輸入靈敏度」：開啟
- 不要邊打邊開 Discord **直播 / 螢幕分享**（很吃效能）
- 有卡音可在語音頻道設定把「區域」手動設成 **Hong Kong / Japan / Singapore** 試試

## 五、Windows 設定（只需做一次）

1. **開機自動啟動的程式**：`Ctrl+Shift+Esc` 開工作管理員 →「啟動應用程式」→ 把用不到的（Spotify、Steam、Teams、Edge…）都「停用」。
2. **硬體加速 GPU 排程**：`設定 > 系統 > 顯示器 > 圖形 > 變更預設圖形設定` → 開啟，重新開機。
3. **指定鬥陣特攻用獨立顯示卡**（筆電必做）：`設定 > 系統 > 顯示器 > 圖形` → 新增 `Overwatch.exe` → 選「高效能」。
4. **虛擬記憶體改回自動**：`Win+R` 輸入 `sysdm.cpl` →「進階」→ 效能「設定」→「進階」→ 虛擬記憶體「變更」→ 勾選「自動管理所有磁碟機的分頁檔大小」→ 重開機。
5. **Battle.net 掃描與修復**：Battle.net → 鬥陣特攻 → 「開始遊戲」旁的齒輪 →「掃描與修復」。
6. **移到 SSD**（若健檢說在 HDD）：Battle.net 齒輪 →「顯示於檔案總管」，或解除安裝後重裝到 SSD 槽。

## 七、做完還是會光球？

那通常就是硬體瓶頸了：

- **顯示卡 VRAM ≤ 4GB 或只有內顯** → 材質品質維持「低」是唯一解，或升級顯示卡。
- **遊戲在 HDD** → 加裝一顆 SSD（500GB 約 NT$1,000 上下）效果最明顯。
- 記憶體若是**單通道**（只插一條 16GB），改成 **2×8GB 雙通道**，內顯電腦提升特別大。可用免費軟體 CPU-Z（https://www.cpuid.com/softwares/cpu-z.html）的「Memory」頁看 Channel 是 Single 還是 Dual。
